# ADR-004：领域层保持框架无关

- 状态：接受
- 日期：2026-08-11

## 背景

自动排程、目标和消费等规则需要长期演进并可被 API、后台任务和 AI 复用。

## 决策

依赖方向为 `kernel → domain → application → infrastructure/interface`；领域层不得依赖 Fastify、React、数据库 ORM 或具体 AI SDK。

## 备选方案

按页面直接写业务逻辑交付快，但规则会分散且难以测试。

## 后果与重新评估

需要显式端口和映射代码，换取可测试和可替换性。只有边界产生持续且无价值的重复时重新评估粒度。
