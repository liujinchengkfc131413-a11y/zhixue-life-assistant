# ADR-008：今日时间流使用可替换 Canvas Renderer

- 状态：接受
- 日期：2026-08-11

## 背景

今日页要把 24 小时以动态水流表达，不同压力和活动类型影响粗细与速度，同时界面风格将在第二版细化。

## 决策

将时间语义、采样数据和 Canvas 渲染器分离，通过稳定 Renderer 接口接入，并保留无动画和可访问降级视图。

## 备选方案

DOM 动画易受节点规模影响；把语义写死在 Canvas 中会阻碍测试和移动端复用。

## 后果与重新评估

初期需要额外抽象，但视觉系统可替换。若 SVG 或 WebGL 在原型验证中明显更合适则新建 ADR。
