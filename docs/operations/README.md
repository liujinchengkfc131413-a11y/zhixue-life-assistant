## 快速入口

- **启动应用**：双击桌面快捷方式「知雪的生活助手」或 `LifeAssistant.exe`，浏览器会自动打开工作台；关闭浏览器后服务继续在后台运行，可从托盘重新打开。
- **数据安全**：所有数据保存在首次启动时选择的数据目录；建议按 [备份与恢复](./备份与恢复.md) 设置自动备份。
- **遇到问题**：先看 [故障处理](./故障处理.md)，或从设置页「诊断信息」导出诊断包协助排查。
