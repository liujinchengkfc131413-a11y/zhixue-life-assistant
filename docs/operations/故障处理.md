# 故障处理

## 常见问题速查

| 现象 | 处理 |
|---|---|
| 双击启动器无反应 / 浏览器未打开 | 检查托盘图标是否存在；右键托盘 →「查看状态」；若服务未运行，右键 →「重启本地服务」。仍不行按下方「诊断信息」导出诊断包。 |
| 启动时提示「找不到本地服务入口」 | 发布目录不完整（缺少 `app\server\main.cjs`）；重新解压发布目录，或检查是否误删了 `app\` 文件夹。 |
| 页面提示「本地服务暂时无法连接」 | 服务进程可能已退出；从托盘「重启本地服务」。若端口被占用，重启后会自动换用可用端口。 |
| 提示「数据尚未初始化」/ 首次向导重复出现 | 数据目录 `metadata.json` 缺失或损坏；若确认需要恢复，使用 [备份与恢复](./备份与恢复.md) 从备份恢复。 |
| 浏览器打开的是默认浏览器而非 Chrome/Edge | 启动器按 Chrome → Edge → 系统默认顺序发现浏览器；本机只有非标准安装路径时回退到系统默认。 |
| 无法保存设置 / 版本冲突提示 | 同一对象被多个页面编辑时会出现；刷新页面后再操作。 |

## 诊断信息与诊断包

设置页「诊断信息」面板：

- **复制诊断信息**：复制版本、Schema、数据目录 ID、后台任务、磁盘与日志文件概况（**不含个人内容与密钥**）。
- **导出诊断包**：生成 ZIP（存放在数据目录 `cache\`），内含脱敏后的诊断信息与最近日志，可用于反馈问题。
- **查看脱敏日志尾部**：折叠展示最近日志片段，密钥与敏感信息已被替换为 `[REDACTED]`。

接口形式：

```
GET  /api/v1/system/diagnostics
POST /api/v1/system/diagnostics:export
```

## 日志

- 位置：数据目录 `logs\`（`app.log`，轮换文件 `app.log.1` …）。
- 格式：JSON 行，含类别（startup / database / background / ai / backup / 等）与级别。
- 轮换：按大小（默认 5 MB）自动轮换，最多保留 5 个轮换文件。
- 脱敏：所有日志在写入前经过脱敏器，API Key、Bearer Token、Authorization 等均不会落入日志。

## 崩溃与恢复

- **数据库**：SQLite 以 WAL 模式运行；进程被强制终止或断电时，已提交数据不会丢失，未提交事务自动回滚，重启后数据库保持完整（`quick_check` 校验通过）。相关演练见 `apps/server/test/m8-009-crash-recovery.drill.test.ts`。
- **后台任务**：任务执行中被终止后，重启时自动恢复过期租约并补跑；同一幂等键不会重复入队。
- **恢复/迁移中断**：备份恢复与目录迁移均为「预检 → 原子切换 → 失败回滚」设计，中断不会破坏当前数据。

## 隐私与安全

- 应用仅绑定本机回环地址（127.0.0.1），不对外提供网络服务。
- AI API Key 保存在 Windows 凭据管理器，不进入数据库、备份、日志或诊断包。
- 发布包不含开发密钥、测试个人数据或绝对源码路径（`pnpm release:verify` 会逐文件扫描）。

## 需要人工处理的场景

- 数据目录磁盘空间不足：自动备份会失败并记录 `FAILED`；腾出空间后下一次自动备份即可恢复。
- 恢复了旧版本备份后 AI 不可用：在 AI 设置中重新填写 API Key。
- 发布目录被移动后桌面快捷方式失效：从托盘菜单「创建桌面快捷方式」重新生成。
