# 使用说明

「知雪的生活助手」是本地优先的个人生活助手：无需联网即可使用核心功能，所有数据保存在你自己的电脑上。

## 安装与启动

1. 将发布目录（例如 `LifeAssistant-0.1.0`）复制到任意位置，例如 `D:\Apps\LifeAssistant`。**无需安装 Node.js、数据库或任何开发环境**。
2. 双击 `LifeAssistant.exe`（或桌面快捷方式「知雪的生活助手」）。
3. 首次启动会：
   - 自动选择可用端口并启动内置的本地服务（使用发布目录自带的 `runtime\node.exe`）；
   - 在默认浏览器中打开工作台页面；
   - 在系统托盘驻留图标（重新打开页面、查看状态、重启服务、退出）。

> 关闭浏览器窗口不会停止服务；从托盘可随时重新打开。应用保证单实例：重复双击只会把已有窗口带到前台，不会启动第二个服务。

## 首次设置

首次打开工作台会进入设置向导：

1. **选择数据目录**：所有业务数据、附件、备份与日志都保存在这里（默认建议 `文档\LifeAssistantData`）。
2. **选择演示数据**：可选七个模块的示例数据用于熟悉功能，之后可在设置页一键清空。
3. **设置自动备份**：选择备份频率（每天/每周/仅手动）与保留份数。
4. **选择快速记录默认动作**：放入收集箱，或交给 AI（未配置 AI 时始终放入收集箱）。
5. **可选配置 AI**：可跳过；未配置时核心产品功能完整可用。

## 发布目录结构

```text
LifeAssistant/
├─ LifeAssistant.exe          # 启动器（托盘、单实例、浏览器打开）
├─ runtime/node.exe           # 私有 Node 运行时
├─ app/
│  ├─ server/                 # 本地服务（含 better-sqlite3 原生依赖）
│  ├─ web/                    # 工作台静态页面
│  └─ package-manifest.json   # 发布清单（版本、Git、Schema、文件 SHA-256）
├─ assets/                    # 品牌资源预留
└─ runtime.json               # 版本与启动策略信息
```

## 数据目录结构

```text
LifeAssistantData/
├─ database/life-assistant.db  # 主数据库（SQLite WAL 模式）
├─ attachments/                # 附件文件
├─ backups/                    # 本地备份包
├─ logs/                       # 日志（按大小轮换，默认 5 MB × 5）
├─ cache/                      # 可重建的临时数据（备份/恢复暂存等）
└─ metadata.json               # 数据目录元数据（安装 ID 等）
```

## 日常使用要点

- **快捷记录**：全局快捷键 `Ctrl + Shift + Space` 打开快速记录弹层。
- **全局搜索**：`Ctrl + K` 打开搜索。
- **离线可用**：除 AI 对话与节假日联网更新外，全部功能不依赖网络。
- **版本并发**：同一对象被多个窗口编辑时会提示版本冲突，不会静默覆盖。

## 升级

升级到新版本时：

1. 先按 [备份与恢复](./备份与恢复.md) 创建一次手动备份（升级程序也会在迁移旧数据前自动备份）。
2. 退出旧版本（托盘 → 退出）。
3. 用新版本替换发布目录（保留原目录作为回退）。
4. 启动新版本：旧数据会自动迁移（Schema 版本升级），迁移前备份保存在数据目录 `backups\pre-migration-*.db`。
5. 若迁移失败，服务会保持旧数据可用并给出错误信息；用旧版本目录 + 原数据目录即可回退。

## 卸载

退出应用后删除发布目录与数据目录即可（数据目录中 `backups\` 内的备份包可另行留存）。
