## 七、候选版本验收执行记录（2026-08-15）

- **Chrome 全量 E2E**：`pnpm test:e2e` 通过（M1–M8 完整纵向流程，无 AI Key，22.8s）。
- **性能基准**：`pnpm test:performance` 通过——页面全部 ≤2s（today 51ms、calendar 80ms、goal-tree 100ms、work-overview 140ms…）、查询/保存 ≤300ms（tasks 91ms、save-task 167ms…）、搜索 902ms ≤1s。
- **发布目录**：`pnpm release:verify` + `pnpm release:clean-check` 全部通过（46 文件 / 272.4 MB）。
- **收尾修复**：
  1. 性能测试 `app.inject` 的 POST 未声明 `content-type: application/json`（字符串 payload 触发 415→500），已补 `headers`；
  2. E2E 的弹性任务固定使用 WORK 区域，周末作息模板无 WORK 时段导致任务被排到下个工作日、今日页不可见（与运行日期相关），改为 LIFE 区域使其与日期无关；
  3. 基准库从 `test-results/benchmark/` 移至 `fixtures/performance/`——Playwright 运行时会清理 `test-results`（outputDir），基准库此前反复被误删。

## 八、已知限制与候选版本说明

1. **版本**：0.1.0-rc1；数据库 Schema 17；发布目录 `distribution/LifeAssistant-0.1.0`（46 文件 / 272.4 MB）。
2. **Edge**：本机 Edge 为自定义路径精简构建，Playwright 无法驱动；已用 CDP 实测页面加载。完整 Edge E2E 与干净 Windows 虚拟机验收是 rc1 → rc2 的主要收尾项。
3. **AI 真实服务**：适配层契约测试全绿；真实服务商验证需用户提供 API Key（可选，不阻塞候选版本）。
4. **Server 运行时**：便携发布使用 CJS 打包（`main.cjs`，@fastify/* 动态 require 约束），源码仍为 ESM TypeScript。
