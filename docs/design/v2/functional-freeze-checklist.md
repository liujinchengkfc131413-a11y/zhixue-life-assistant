# V2 美术改进功能冻结检查表

> 基线日期：2026-08-23  
> 适用阶段：V2 美术实施 Phase 0–8  
> 原则：视觉改造可以改变样式、布局容器和展示顺序，不得改变下列功能契约。

## 1. 全局契约

- [ ] 路由地址、导航名称、分组和顺序不变。
- [ ] `Ctrl+Shift+Space` 继续打开快速记录，`Ctrl+K` 继续打开全局搜索。
- [ ] Dialog / Drawer 支持 Escape 关闭、键盘焦点约束和关闭后焦点恢复。
- [ ] 加载、空、错误、禁用、成功和危险确认状态均真实展示。
- [ ] 页面继续只通过现有 API 和 Query/Mutation 层读写数据。
- [ ] 不修改 OpenAPI、数据库、后端路由、权限分级和风险确认协议。
- [ ] 不使用伪造生产数据换取视觉相似度。

## 2. Today

- [ ] 四档压力与 Calm / Balanced / Busy / Intense 媒体映射不变。
- [ ] 静态母版回退、reduced-motion、页面隐藏暂停和恢复播放行为不变。
- [ ] 24 小时时间轴、当前时刻、计划、即将开始和弹性任务仍读取真实数据。
- [ ] 任务详情、保存并重新安排、完成任务和手动重排行为不变。
- [ ] Today AI 草稿带入、重试和默认 Provider 不可用提示不变。
- [ ] 已批准的 1536×1024 构图以及 1366/1440/1600/1654/1920 桌面回归无 P0/P1/P2 变化。

## 3. Work

- [ ] 工作总览范围切换、自定义日期和统计展示不变。
- [ ] 自媒体创建、筛选、状态迁移、编辑、删除、表现录入、日历和趋势不变。
- [ ] 开发项目创建、编辑、里程碑、功能、缺陷、仓库链接和笔记附件不变。
- [ ] 学习资源创建、状态、进度、学习记录、笔记和附件不变。

## 4. Life

- [ ] 生活总览范围切换与购物、饮食、健身、娱乐汇总不变。
- [ ] 购物待购、预算、修改、完成购买和消费记录不变。
- [ ] 饮食计划、食谱、实吃、饮水和偏好限制不变。
- [ ] 健身动作、计划、训练、身体指标、个人纪录和恢复状态不变。
- [ ] 娱乐条目、进度、时长、活动/旅行详情和支出不变。

## 5. Plan & Goals

- [ ] 新建目标和新建计划的字段、默认值和提交行为不变。
- [ ] 看板、日历、时间轴、目标树继续读取同一数据。
- [ ] 今日/本周/短期/长期以及工作/生活筛选不变。
- [ ] 手动覆盖进度和恢复自动进度行为不变。

## 6. AI

- [ ] 默认 Provider 解析和未就绪状态不变。
- [ ] 新建会话、查看会话、发送、流式刷新和取消生成不变。
- [ ] 来源链接、Operation Card、查看变更详情和撤销不变。
- [ ] 会话、消息和操作结果继续使用真实本地数据。

## 7. System

- [ ] 收集箱拆分、分类、保存处理结果和归档不变。
- [ ] 数据管理的操作记录、版本历史、恢复、回收站和永久删除不变。
- [ ] 提醒中心未读、已读、稍后提醒和跳转详情不变。
- [ ] 设置保存、分类/标签、备份、数据迁移、演示数据、AI 记忆和节假日行为不变。
- [ ] Setup 三步流程、数据目录、演示数据、备份和快速记录偏好不变。

## 8. 每阶段签核

每个 Phase 完成后必须记录：

1. 本阶段变更文件。
2. 以上受影响条目的自动化测试与人工交互结果。
3. API 请求方法、路径、请求体或触发次数是否发生变化。
4. 未验证或部分验证的条目及原因。
5. Today 是否受共享 Shell、控件或弹窗样式影响。

未完成勾选和证据记录时，不得进入最终交付状态。

## 9. Phase 0 签核（2026-08-23）

- 变更范围：只新增视觉基线、测试编排与冻结文档；未修改页面组件、业务逻辑、API、数据库、数据映射或生产资源。
- 自动化：V2 基线 6/6 通过；全仓 lint、11 包 typecheck、243 项单测、契约检查、11 包 build、Launcher build 通过。
- 浏览器：通过 `BU_CDP_URL=http://127.0.0.1:9333` 的独立 Chrome for Testing 实例，核对 Today 页面身份、导航、真实内容和 43120 用户实例未被隔离测试改写。
- 现有 E2E：单 worker 隔离运行 28 项，21 项通过；当前 AppShell、Today Scene、Today V3 业务与多视口保护均通过。
- 已登记测试债：`today-v2.spec.ts` 中 7 项仍断言已由 Today Scene Final 停运的 Canvas/WebGL 动态水体和旧 `grid-template-areas`，不归因于 V2 美术改进；对应当前实现保护用例 6/6 通过。
- API 变化：无；新增脚本只改变自动化测试端口与数据目录。
- Today 影响：无界面代码变更；目视基线与现有 Scene/V3 自动化均确认当前页面保持原状。
- 未验证：Edge 留在最终跨浏览器验收阶段；本阶段不勾选后续页面改造后的逐条回归项。

## 10. Phase 1 签核（2026-08-23）

- 变更范围：新增全局设计 Token、Work / Life / Vision / AI / System 主题映射、共享控件/表单/列表/状态/弹窗视觉基础，以及 AppShell `data-theme` 路由映射；未调整路由、导航名称与顺序、业务组件数据流、Query/Mutation、API、数据库或权限语义。
- 自动化：主题路由映射与共享 LoadingState 单元测试 17/17 通过；V2 Foundations 隔离 Playwright 4/4 通过；全仓 lint、主题 CSS 审计、11 包 typecheck、257 项单测（2 项按设计跳过）、契约检查、11 包 build 与 Launcher Release build 通过。
- 浏览器：在 43123 独立数据目录验证 Work、Life 与 Today 页面身份；Work / Life 无横向溢出、无框架错误层或控制台 warning/error；快速记录打开后焦点位于“记录内容”，Escape 可关闭；Today 为 `data-theme="today"`、时间轴存在、无横向溢出。
- 视觉：五个非 Today 空间已应用各自主题；快速记录和全局搜索统一为 System Surface；1536×1024、1654×960、1920×1080 三档 Today 保护截图均已生成并目视复核。
- API 变化：无。快捷键、弹窗提交、数据请求方法/路径/请求体和触发次数未修改。
- Today 影响：新主题规则均以 `.app-shell:not([data-theme="today"])` 或主题属性为作用域；像素对比的变化仅落在实时钟/动态媒体区域，没有发现共享 Shell、控件或弹窗样式侵入 Today。
- 未验证：Edge 仍按计划留在最终跨浏览器验收阶段；Phase 1 不勾选尚未进入页面级改造的 Work / Life / Vision / AI / System 业务条目。
