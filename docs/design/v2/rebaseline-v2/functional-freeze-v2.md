# V2 新计划 Phase 0 · 功能冻结清单

> 日期：2026-08-25  
> 状态：已签核  
> 作用：保护新版美术重构期间的既有产品行为

## 1. 全局契约

- 路由和导航信息架构不变。
- `AppShell` 继续输出 `today / work / life / vision / ai / system`。
- 快速记录支持侧栏入口与 `Ctrl + Shift + Space`。
- 全局搜索支持侧栏入口与 `Ctrl + K`。
- Dialog 支持 Escape 关闭与正确焦点进入。
- 所有视觉测试使用隔离 Bootstrap、数据目录和端口，不连接 43120 用户实例。

## 2. 页面契约

- Today：场景媒体、压力状态、计划区、未来四小时、弹性任务、24 小时时间轴与 AI Composer 保持可用。
- Work：总览、自媒体、开发项目、学习四入口及其筛选、选择、详情和表单保持可用。
- Life：总览、购物、饮食、健身、娱乐五入口及其选择、详情和表单保持可用。
- Vision：目标 / 计划创建与看板、日历、时间轴、目标树四视图共享同一数据。
- AI：会话创建、消息、工具结果、确认、变更和撤销语义不变。
- Inbox：筛选、选择、处理、归类与归档语义不变。
- Data：历史、回收站、恢复和危险操作确认语义不变。
- Reminders：已读、稍后提醒和跳转对象语义不变。

## 3. Phase 0 验证

- 新版 Rebaseline Playwright：6/6 通过。
- 1536×1024 全部 16 路由成功渲染并匹配 Theme。
- 三档扩展视口六空间代表路由成功渲染。
- 34 个页面 / 视口组合的页面级横向溢出均为 0。
- 已配置应用无 console warning / error、page error 或 Vite Error Overlay。
- 独立 Chrome for Testing 9333 + browser-harness 完成 Work → Life → 快速记录 → Escape 交互复核。

## 4. 允许的后续展示层调整

- 可以调整页面 DOM 分区、CSS 类名、布局、材质、背景、环境层和视觉状态。
- 可以为可访问性增加语义属性和更清晰的焦点结构。
- 不得借美术重构重写 API Hook、mutation、权限、数据模型或业务规则。
- Vision 和 AI 在移动展示结构前，必须先补齐对应行为回归测试。

## 5. 已知基线行为

- 未完成初始化时，Shell 会探测尚不可用的业务接口并产生资源 500；完成初始化并刷新后控制台必须为 0。
- AI 未配置默认服务时保持不可发送，并引导用户前往设置。
- 动态时钟和 Today 场景媒体不参与严格像素一致性判断。
- 本清单冻结行为，不认可旧 Work / Life 的颜色、材质或心理感受为新版完成状态。
