# V2 母版复刻与产品适配边界

> 决策日期：2026-09-10
> 适用空间：Work、Life、Plan & Goals、AI Assistant
> 决策结论：母版负责空间身份与内容材质，产品家族层和真实业务结构不由母版示例覆盖。

## 1. 三层裁决模型

| 层级 | 由谁定义 | 必须保持的内容 | 是否允许偏离母版示例 |
|---|---|---|---|
| 产品家族层 | App Shell / PRD | Sidebar、品牌、导航分组、图标语言、快捷入口、全局弹窗、字体、焦点与键盘规则 | 允许；以统一产品规则为准 |
| Theme Environment | 四张正式母版 | 背景构图、环境光、雾、色温、空间纵深、内容区 Card / Field / Button 的材质与明暗关系 | 不允许无依据偏离 |
| 真实业务层 | 总 PRD、数据库与 API 设计 | 路由、视图、字段、业务状态、数据关系、操作链路、错误与空状态 | 允许重新排布；不得删减或伪造能力 |

## 2. Sidebar 正式裁决

- Work、Life、Plan & Goals、AI Assistant 与 System 共享当前深色导航壳，形成稳定的产品家族锚点。
- 空间差异通过 Active Accent 表达，不改变导航底色、信息架构、图标体系、几何和交互。
- 不依据四张母版分别制作冷蓝、浅鼠尾草、Vision 蓝或 AI 紫四套 Sidebar。
- Today 按已确认的 Today Scene 保留轻色场景侧栏；它是首页场景方案的独立例外，不反向要求其余空间分裂为多套导航。

## 3. Plan & Goals 允许适配

必须复刻：

- 远景山谷、右上晨光、冷蓝雾场与空间纵深。
- Air Glass 的通透度、细亮边框、蓝紫选择态与轻量层级。
- 看板作为轻空间容器，而不是厚重卡片墙。

允许适配：

- 母版示例卡片的数量、标题、文案、顺序和具体尺寸。
- 为真实看板、日历、时间轴、目标树和进度编辑保留工具栏、筛选、滚动与响应式重排。
- 创建目标、创建计划的表单可折叠或按真实操作流程展开，但必须保留全部真实字段和清晰入口。

禁止：

- 为追求截图高度删除真实控制、隐藏业务视图或使用不可操作的示例卡片。
- 将 Vision 改成星空、粒子、霓虹宇宙或厚重 Work 风格。

## 4. AI Assistant 允许适配

必须复刻：

- Vision 家族远景、AI 专属蓝紫弧光和低密度静态星点裁决。
- 会话选中态、Composer、Operation Card 的细亮边框与柔和 Active Glow。
- “会话列表 + 主对话”两区结构，以及连续文档式 AI 回复。

允许适配：

- 母版示例消息、上下文内容、按钮文案和卡片数量。
- 工具结果通过 Expandable Card、Drawer 或按需 Context Panel 展开，不默认常驻第三栏。
- 根据真实会话长度、来源引用、确认流程、失败状态和撤销状态调整内容高度与信息密度。

禁止：

- 为复制概念图加入尚无 PRD / API 支撑的假按钮、假工具或假上下文。
- 弱化 Operation Card、风险确认、来源引用或撤销入口以换取画面简洁。
- 将页面改成传统气泡聊天 App 或永久三栏后台。

## 5. QA 裁决方式

每次视觉验收分别记录：

1. **母版复刻 Ledger**：环境、光、雾、色温、内容材质是否与母版一致。
2. **产品适配 Ledger**：Sidebar、真实数据、业务结构、响应式和可访问性差异是否属于本文件授权范围。

只有第一类差异是母版 Fidelity 缺陷。第二类差异只要符合 PRD 和统一产品规则，就应记录为“已确认适配”，不得重复开单。
