# Phase 5 — AI Assistant 验收说明

> 基准母版：`../work-life-color-masters-v2/vision-ai-assistant-master-v2-1448x1086.png`  
> 基准视口：1448 × 1086；扩展视口：1536 × 1024、1366 × 768、1920 × 1080、1100 × 900  
> 隔离数据：`test-results/v2-assistant/data`

## 阶段范围

- 将旧设置列表重组为 `Session List + Main Conversation` 两区布局。
- User 消息使用紧凑轻气泡；AI 回复使用连续文档流。
- 变更集使用高权重 Operation Card，并保留详情展开与撤销入口。
- Composer 与当前会话选中态复刻母版的细亮边框、蓝紫弧光与柔和泛光。
- 使用独立的 AI 远景背景资产，保留山谷纵深、右上蓝紫弧光与少量静态星点。

## 功能冻结

API、SSE、默认模型判断、发送、取消、变更集读取、撤销与时间系统刷新逻辑保持原有边界；本阶段只调整展示 DOM、样式与键盘提交入口。

## 验证

运行：

```bash
pnpm test:e2e:v2-assistant
```

该命令创建隔离数据目录，并验证五档视口、主题背景、reduced-motion、会话切换、键盘发送、新建会话、失败消息、Operation Card 展开和撤销。截图与 `assistant-metrics.json` 由测试写入本目录。

2026-08-26 最终实测结果：3 项 Playwright 用例全部通过（32.4 秒）。V2 Theme CSS 审计、全仓 TypeScript 检查、257 项单元/集成测试、契约检查、ESLint 与生产构建同批通过；Chromium Browser 复核确认页面标题/路由正确、首屏非空、无框架错误覆盖层、console error/warning 为 0，会话标题输入可更新本地 UI 状态。生产构建仍报告项目已登记的主 chunk 大于 500 kB 提示，本阶段未新增 JavaScript 视觉依赖。

## 人工视觉对照

- 背景：母版的蓝色山谷纵深、左下树影、右上蓝紫弧光与稀疏星点均存在。
- 结构：桌面为会话列表 + 主对话两区，没有引入永久第三栏。
- 消息：User 为紧凑气泡，AI 为无大卡包裹的连续文档流。
- Operation：结构卡权重高于聊天正文，状态、详情与撤销入口均可见，但未使用大面积常驻 Glow。
- 交互高光：选中会话与 Composer 使用母版式细紫边、白亮轮廓和双层柔光；正文对比度未被光效覆盖。
- 响应式：1448×1086 母版视口及四档扩展桌面视口均无页面级横向溢出；1100×900 下仍保持可用两区布局。

遗留事项：本阶段未改动真实模型供应商配置流程，也未引入附件或工具选择等母版中的概念性按钮；这些不属于 Phase 5 美术重构授权范围。

## 视觉裁决记录

《生活助手 V2 美术设计规范 V2》对 Vision 通用背景写有“禁止星星”，但用户确认的 AI 正式母版与 Phase 5 本次明确要求均含少量星点。本实现仅在 AI 专属静态背景的弧光附近保留稀疏星点，不加入粒子动画、银河或宇宙主题；Plan 页面不受影响。
