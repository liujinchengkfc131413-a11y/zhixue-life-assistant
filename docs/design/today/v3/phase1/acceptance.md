## 与最终概念图仍存在的差异

- 喷泉仍使用已有摄影合成资产，水体亮度、空气感与背景融合度尚未达到概念图；属于 Phase 2–4 的场景、材质与渲染任务。
- 右栏内容沿用真实 Today 数据结构，卡片内部排版尚未完全复刻概念图；属于后续信息密度与交互阶段。
- 侧栏品牌区仍使用当前产品文案与图标体系，没有伪造概念图中的头像、天气或农历数据。
- 当前时间轴采用真实计划分段，不追求与概念图相同的示例时长。
