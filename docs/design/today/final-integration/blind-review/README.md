# Today Scene 四状态动态盲测

## 目的

验证在不显示压力数值、状态名称和业务文案时，评审者能否只依据水景动态区分 Calm、Balanced、Busy、Intense。

## 使用方式

1. 使用本地静态服务器从仓库根目录提供文件，例如 `python3 -m http.server 43131`。
2. 打开 `/docs/design/today/final-integration/blind-review/`。
3. 由未查看视频文件名与答案映射的独立评审者完成 8 个匿名片段。
4. 完成后优先下载结果 JSON，并将文件放入本目录的 `results/`；若未保留逐题 JSON，则必须在 `results/` 中如实记录评审者明确反馈的准确率、结论与证据边界。

可在 URL 使用 `?seed=20260910` 固定批次顺序，以便复验。同一批次含四个状态各两次，并从两个不同相位开始播放。

## 通过标准

- 总正确率至少 6 / 8（75%）。
- Calm、Balanced、Busy、Intense 每个状态至少正确识别一次。
- 不允许跨级误判，即 Calm 不得判断为 Busy / Intense，Balanced 不得判断为 Intense，反向同理。

页面会自动计算结果，但自动化只能证明匿名、播放、选择、计分和下载流程可用。没有独立评审者的结果 JSON 或明确验收记录时，不得写成“人工盲测已通过”。

## 2026-09-14 映射校准

依据 2026-09-10 的首轮录屏辨识结果，仅交换两组“业务状态 → 既有视频资产”映射：Calm 使用原 Balanced 素材，Balanced 使用原 Calm 素材；Busy 使用原 Intense 素材，Intense 使用原 Busy 素材。视频文件、播放速度、压力阈值与页面布局均未修改。

本次校准后必须重新进行独立人工盲测；首轮结果和按答案重算的预测仅用于确定交换方案，不作为新映射已通过的证据。校准后的用户复验结果记录于 `results/2026-09-14-user-confirmation.md`。

## 证据边界

- 盲测使用生产环境正在加载的四个 MP4 原文件，不转码、不重新剪辑、不叠加压力 UI。
- 文件路径存在于页面源码中，因此评审者不得打开开发者工具或查看 HTML 源码。
- 单次通过只说明本批次可辨识；更换视频资产后必须重新评审。
