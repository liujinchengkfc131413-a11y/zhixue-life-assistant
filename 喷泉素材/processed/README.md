## 处理方式

1. 对每段 8 秒、24 fps 原视频逐帧检测尾部运动量。
2. 按各视频实际停顿起点移除尾部低运动区，而非统一粗剪 1 秒。
3. 使用 0.5 秒交叉融合修复原始首尾跳变。
4. 将最终循环边界旋转到原视频中段的连续运动帧，使播放器从末帧回到首帧时仍是自然的相邻水流运动。
5. 输出为 H.264 High Profile、`yuv420p`、1152×768、24 fps、无音轨，并写入 fast-start 元数据。
